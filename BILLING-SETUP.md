# Подготовка ЮKassa и чеков

Приём реальных платежей отключён. Дневной тариф стоит 50 ₽ и действует 24 часа без ограничения скачиваний. Месячный и годовой тарифы сохраняют свои условия. Остатки баланса удаляются при обновлении, история платежей сохраняется.

В разделе «Настройки» админки можно сохранить идентификатор магазина и секретный ключ ЮKassa. Ключ шифруется, файл `payment-settings-key` в постоянном каталоге `DATA_DIR` нужно резервировать вместе с базой. Не передавайте ключ в переписке и не публикуйте его в репозитории.

Для проверки используйте отдельную базу и тестовый магазин с ключом `test_…`. `BILLING_ENABLED=1` предназначен только для изолированного тестирования. Тестовые платежи не меняют действующие тарифы. Сервер сверяет состояние платежа непосредственно с API ЮKassa.

В настройках уведомлений магазина укажите `https://конторка.рф/api/yookassa/webhook` и события `payment.succeeded`, `payment.canceled`, `refund.succeeded`. В кабинете ЮKassa необходимо настроить «Чеки от ЮKassa» и налоговый режим ИП: АУСН 8%, без НДС. Перед запуском реальных платежей необходимо реализовать и проверить выдачу чеков, обработку возвратов и сверку статусов. При платном скачивании PDF и изменения временно передаются на сервер для сборки результата.
