# ZaPDF — подпись PDF

Сервис визуального подписания PDF. Можно подписать файл в браузере или создать отдельные ссылки для последовательного подписания несколькими людьми.

## Возможности и ограничения

- Самостоятельное подписание выполняется в браузере, без отправки документа на сервер.
- В редакторе можно добавлять PDF и пустые страницы, менять порядок, поворачивать и удалять страницы, добавлять текст, галочки, подписи и печати, перемещать и менять размер объектов, а затем скачать PDF.
- Чтобы ввести текст, выберите «Добавить текст», нажмите на документ и печатайте прямо на странице. Сохранять текст как заготовку необязательно. При скачивании текст добавляется в PDF как изображение и не становится поисковым или редактируемым текстом PDF.
- Подпись или печать можно нарисовать либо загрузить из PNG, JPG, WebP или SVG размером до 10 МБ; фотографию можно также передать с телефона по одноразовому QR-коду (PNG, JPG или WebP). Доступны обрезка, настройка размера, наклона и удаления фона прямо на документе. У новых подписей сохраняется исходное изображение, чтобы можно было менять обработку повторно; для старых подписей восстановление уже удалённого фона требует повторной загрузки оригинала.
- Без входа подписи, печати и тексты хранятся в браузере. После входа по почте заготовки сохраняются на сервере и доступны на других устройствах. В аккаунте можно явно скопировать существующие локальные заготовки, сохранив их в браузере. При переходе с gamelife.shop локальные заготовки сначала нужно скопировать в аккаунт на старом домене, а затем войти в тот же аккаунт на zapdf.ru.
- Временное фото с телефона хранится в памяти сервера до получения браузером или до 10 минут. Доступ к загрузке даёт QR-ссылка; не передавайте её посторонним.
- При запросе другим участникам PDF хранится на сервере до семи дней. Участникам и владельцу выдаются отдельные случайные ссылки; сохраните их при создании — повторно получить их нельзя.
- Ссылки являются секретом: любой обладатель ссылки подписанта может открыть документ и подписать его. Вход в аккаунт не проверяет личность и не меняет доступ по существующим ссылкам; почтовых уведомлений подписантам нет.
- Подпись является изображением, добавленным в PDF. Это не криптографическая или квалифицированная электронная подпись; проверки подлинности и защищённого журнала аудита нет.
- Размер файла до 20 МБ, до 100 страниц. Защищённые паролем PDF не поддерживаются. Для запросов другим участникам также не поддерживаются повёрнутые и обрезанные страницы.

## Локальный запуск

Требуются Node.js 24 и pnpm 11. Выполните pnpm install, pnpm build, pnpm start и откройте http://localhost:3000. Проверка: pnpm test.

## Развёртывание

Команда docker compose up -d --build запускает приложение и Caddy. Caddy получает сертификат для домена из Caddyfile; порты 80 и 443 должны быть доступны извне. Данные SQLite сохраняются в Docker volume sign_data.

GitHub Actions запускает тесты и сборку. На ветке main после успешной проверки он передаёт архив текущего коммита по SSH ограниченному серверному ключу; необходимы секреты окружения production: DEPLOY_SSH_KEY и DEPLOY_KNOWN_HOSTS. На сервере команда ключа должна безопасно развернуть архив и выполнить docker compose up -d --build.

## Вход по почте

SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD и SMTP_FROM задаются в отдельном файле `.env` на сервере с правами 0600; он не должен попадать в Git. Для SpaceWeb используйте smtp.spaceweb.ru и порт 465 с TLS. Без всех этих настроек вход отключён, а редактор остаётся доступным без аккаунта. Конфигурация должна переживать развёртывания. Папка данных приложения содержит базу аккаунтов и секрет для проверки кодов; оба необходимо включить в защищённую резервную копию.

Для доставки настройте SPF, DKIM и DMARC в соответствии с инструкциями почтового провайдера и проверяйте заголовки настоящих писем. На репутацию влияют также жалобы, ошибки адресов и история отправителя; гарантировать отсутствие писем в спаме нельзя. Проверку подлинности почтового адреса и ограничения запросов не следует отключать.
