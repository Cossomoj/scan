# Конторка — подпись PDF

Сервис визуального подписания PDF. Можно подписать файл в браузере или создать отдельные ссылки для последовательного подписания несколькими людьми.

## Возможности и ограничения

- При самостоятельной работе документ редактируется в браузере. При включённой оплате исходный PDF и изменения временно передаются на сервер для формирования файла при скачивании, в том числе бесплатном. Word и Excel временно отправляются на сервер для преобразования в PDF.
- В редакторе можно добавлять PDF и пустые страницы, менять порядок, поворачивать и удалять страницы, добавлять текст, галочки, подписи и печати, перемещать и менять размер объектов, а затем скачать PDF.
- Чтобы ввести текст, выберите «Добавить текст», нажмите на документ и печатайте прямо на странице. Сохранять текст как заготовку необязательно. При скачивании текст добавляется в PDF как изображение и не становится поисковым или редактируемым текстом PDF.
- Подпись или печать можно нарисовать либо загрузить из PNG, JPG, WebP или SVG размером до 10 МБ. Доступны обрезка, настройка размера, наклона и удаления фона прямо на документе. У новых подписей сохраняется исходное изображение, чтобы можно было менять обработку повторно; для старых подписей восстановление уже удалённого фона требует повторной загрузки оригинала.
- Без входа подписи, печати и тексты хранятся в браузере. После входа по почте заготовки сохраняются на сервере и доступны на других устройствах. При переходе с zapdf.ru или gamelife.shop локальные данные можно сохранить в профиль на старом домене, а затем войти в тот же профиль на конторка.рф.
- При запросе другим участникам PDF хранится на сервере до семи дней. Участникам и владельцу выдаются отдельные случайные ссылки; сохраните их при создании — повторно получить их нельзя.
- Ссылки являются секретом: любой обладатель ссылки подписанта может открыть документ и подписать его. Вход в аккаунт не проверяет личность и не меняет доступ по существующим ссылкам; почтовых уведомлений подписантам нет.
- Подпись является изображением, добавленным в PDF. Это не криптографическая или квалифицированная электронная подпись; проверки подлинности и защищённого журнала аудита нет.
- Для самостоятельной работы поддерживаются файлы до 50 МБ и PDF до 100 страниц; для запросов другим участникам — PDF до 20 МБ. Защищённые паролем PDF не поддерживаются. Для запросов другим участникам также не поддерживаются повёрнутые и обрезанные страницы.

## Тарифы и скачивание

Редактор доступен до входа; при включённой оплате для скачивания требуется аккаунт. Каждому аккаунту, включая ранее зарегистрированные, доступно одно бесплатное скачивание. Бесплатное скачивание не расходуется, пока доступен оплаченный тариф, и сохраняется для последующего использования.

- Бесплатный: одно скачивание на аккаунт, без водяного знака.
- Дневной: 50 ₽ за 24 часа, скачивания без ограничения.
- Месячный: 249 ₽ за 30 дней, до 20 скачиваний.
- Годовой: 1 499 ₽ за 365 дней, до 100 скачиваний.

Повторное скачивание документа расходует новую единицу лимита. Повтор той же операции после ошибки не расходует дополнительную единицу; ошибка формирования PDF не списывает скачивание. После исчерпания бесплатного скачивания и при отсутствии оплаченного тарифа редактор предлагает выбрать тариф. Оплата открывается в новой вкладке, чтобы документ оставался в редакторе.

Автоматического продления нет. При покупке нескольких тарифов следующий начинается после окончания срока действующего либо исчерпания его лимита. Срок и оставшееся количество скачиваний видны в профиле. Условия интеграции с ЮKassa и чеков описаны в [BILLING-SETUP.md](BILLING-SETUP.md).

## Локальный запуск

Требуются Node.js 24 и pnpm 11. Выполните pnpm install, pnpm build, pnpm start и откройте http://localhost:3000. Проверка: pnpm test.

## Развёртывание

Команда docker compose up -d --build запускает приложение и Caddy. Caddy получает сертификат для домена из Caddyfile; порты 80 и 443 должны быть доступны извне. Данные SQLite сохраняются в Docker volume sign_data.

GitHub Actions запускает тесты и сборку. На ветке main после успешной проверки он передаёт архив текущего коммита по SSH ограниченному серверному ключу; необходим секрет окружения production DEPLOY_SSH_KEY. Публичный ключ сервера закреплён в конфигурации workflow. На сервере команда ключа разворачивает архив и запускает сервис с сохранёнными настройками и данными.

## Вход по почте

SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD и SMTP_FROM задаются в отдельном файле `.env` на сервере с правами 0600; он не должен попадать в Git. Для SpaceWeb используйте smtp.spaceweb.ru и порт 465 с TLS. Без всех этих настроек вход отключён, а редактор остаётся доступным без аккаунта. Конфигурация должна переживать развёртывания. Папка данных приложения содержит базу аккаунтов и секрет для проверки кодов; оба необходимо включить в защищённую резервную копию.

Для доставки настройте SPF, DKIM и DMARC в соответствии с инструкциями почтового провайдера и проверяйте заголовки настоящих писем. На репутацию влияют также жалобы, ошибки адресов и история отправителя; гарантировать отсутствие писем в спаме нельзя. Проверку подлинности почтового адреса и ограничения запросов не следует отключать.
