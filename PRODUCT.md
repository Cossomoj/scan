## Platform

web

## Product Purpose

A Russian-language PDF signing and filling service at zapdf.ru. The previous gamelife.shop address stays available during migration so existing local browser data and signing links remain accessible.

## Users

People filling and signing their own PDFs, including forms, applications and contracts. The user explicitly confirmed this as the primary homepage scenario on 2026-10-31. Invitations remain available as a secondary action.

## Capabilities and Constraints

React/Vite application with a Node backend, Docker and GitHub Actions. Self-editing stays in the browser. PDFs up to 20 MB and 100 pages. Add uploaded or drawn signatures, stamps, editable overlays, checks and pages; adjust image background, scale and angle; download the result. Saved text/signature assets stay in this browser. Added text exports as an image. The service does not replace or edit original PDF text.

Invitations create separate links for up to ten sequential signers and upload the document to the server for seven days. There is currently no email delivery service. The visual signature is not a qualified electronic signature. No registration or payment is required by the existing implementation.

## Brand Commitments

Existing name: Лист. Clear everyday Russian. The user has authorized redesign of the homepage. Editor and invitation behavior must continue working.

## Evidence on Hand

Working editor and synthetic demonstration documents. No verified user counts, testimonials, security certifications or speed guarantees: do not invent them. Do not publish user-uploaded private document examples.

## Product Principles

- Let visitors open a PDF immediately.
- Explain capabilities through working examples.
- Distinguish local editing from server-backed signing links.
- Keep templates optional and preserve current editing workflows.
